# 🛸 Mid360 雷达专属导航栈 (diuniu_nav)

本功能包是为“地牛”叉车 AGV 在使用**大疆览沃 Mid360 3D 激光雷达**时，专门定制的导航与定位技术栈。它集成了最前沿的 **FAST-LIO 3D 激光里程计** 作为底层 SLAM 核心，能够应对各种复杂的工业和仓储环境，提供极高精度的 3D 点云匹配定位。

---

## 🚀 快速启动

本功能包提供了基于 3D 点云建图的 2D 切片地图（默认加载路径为 `maps/map.yaml`），内部串联了 Mid360 驱动、底盘通信、FAST-LIO 定位以及 Nav2 核心规划模块。

### 1. 一键启动全套导航栈
无需任何参数，直接运行：
```bash
ros2 launch diuniu_nav diuniu_nav_all.launch.py
```

### 2. RViz2 可视化与交互
在新的终端窗口中运行以下命令打开预设界面：
```bash
rviz2 -d /home/y/GZ_DiNiu_ws/src/diuniu_nav/rviz/diuniu_nav.rviz
```

> [!NOTE]
> **与 N10 栈的不同之处**：
> 在基于 FAST-LIO 的 3D 导航栈中，系统不需要您在 RViz 里手动提供 `2D Pose Estimate`！FAST-LIO 启动后会自动进行 3D 环境特征匹配并计算出机器人的初始位姿。您只需要确保在启动环境与上次建图环境的特征高度一致（不要在纯空旷无特征的环境下冷启动），即可直接下发 `Nav2 Goal` 开始导航。

### 3. 独立手柄遥控 (可选)
如果需要手动遥控，在独立终端运行：
```bash
ros2 launch betop_teleop diuniu_teleop_cmd_vel.launch.py
```

## 🛠️ 核心架构与黑科技优化

本功能包针对 3D LiDAR 栈的特性，做出了大量底层适配，并同步了与 N10 栈一致的“极限制导”策略：

| 优化项 | 原理与效果 |
| :--- | :--- |
| **3D 点云切片与自遮挡** | Mid360 视角极广（球形视场）。系统使用高度切片（`min_height: 0.10`）剔除地面噪点，并在配置文件中拉长盲区屏蔽盒至 `[-0.35m, 1.95m]`，抠除车身与货叉点云，只留下真实的外部环境特征，防止自锁死。 |
| **解锁 90度 原地转向** | 彻底解除物理封印！最小转弯半径 (`minimum_turning_radius`) 极度压缩至 `0.05m`，纯追踪前瞻距离 (`min_lookahead_dist`) 降至 `0.50m`。系统会在极其狭窄的仓库货架间，利用“原地打转”的极限机动能力进行倒车对孔和直角转弯。 |
| **直道画龙抑制** | 修正了 `velocity_smoother` 与 RPP 控制器 `max_velocity` 不匹配导致的等效转向增益过大的问题。代价惩罚系数 (`cost_penalty`) 降至 `1.2`，使全局路径更加顺滑平直，不再因微小环境噪点产生蛇形走位。 |
| **TF 解耦与看门狗** | 由 FAST-LIO 全权接管 `map -> odom -> base_link`，主动关闭底盘单片机虚假 odom 广播，避免 TF 撕裂。引入 0.2s 毫秒级刹车看门狗，杜绝 CPU 过载时的“丢码盲倒”事故。 |

## 📂 目录结构与配置入口

- **`config/nav2_params.yaml`**：Nav2 核心算法池，包含了专门针对 Mid360 3D 转换 2D 代价地图的参数优化、RPP 控制器设定和防撞轮廓配置。
- **`behavior_trees/`**：存放了移除了 `Spin` 恢复行为的定制化行为树，防止三轮车在狭小空间内原地甩尾扫倒货物。
- **`launch/diuniu_nav_all.launch.py`**：主入口脚本，包含 FAST-LIO、驱动、TF 树和 Nav2 生命周期的组合编排。
- **`maps/`**：由 `pcd2pgm` 转换而来的高精度 2D 栅格地图文件，供全局路径规划使用。

## 🛑 故障排查

> [!WARNING]
> **Q: 启动后在原地抽搐或倒车时一直停住？**
> 
> **A:** 请检查是否误触发了 `collision_monitor`（碰撞急停监控）。我们为地牛设定了后方 `1.0m` 扇形极速刹停区，以及全身 `1.2m` 半径的减速区，任何进入此范围的噪点都会锁死底盘。您可以调整 FAST-LIO 的滤波尺寸 `filter_size_surf/map` 以降低 3D 噪点密度，或者检查周围是否有人或物体过近。
