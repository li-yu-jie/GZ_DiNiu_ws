# N10 雷达专属导航栈 (diuniu_n10_nav)

本功能包是为“地牛”叉车 AGV 在使用**镭神 N10 2D 激光雷达**时，专门定制的导航与定位技术栈。它完全独立于基于 Mid360 的 `diuniu_nav`，采用了极简、高效的 2D 激光定位（AMCL）和专门调优的路径规划控制逻辑。

## 🚀 快速启动

本功能包自带默认地图（`maps/map.yaml`），且内部已对齐所有必需的节点（包括雷达驱动、底层 TF、AMCL 定位、Nav2 核心）。
无需传递任何参数，即可一键启动完整导航栈：

```bash
ros2 launch diuniu_n10_nav n10_nav_all.launch.py
```

启动后，打开 RViz：

```bash
rviz2 -d /home/y/GZ_DiNiu_ws/src/diuniu_nav/rviz/diuniu_nav.rviz
```

**初始位姿（已自动化）**：AMCL 已配置 `set_initial_pose: true`，初值 = 固定停车位（即 `diuniu_nav/maps/waypoints.json` 的「初始位置」，两栈地图同原点，坐标通用）。从停车位开机时系统自动定位，**无需手动标位姿**，可直接下发目标点。

若从别处开机，AMCL 会先锁定停车位坐标（位姿错误），此时照旧在 RViz 用 `2D Pose Estimate` 纠正一次即可（AMCL 接受 `/initialpose` 覆盖）；长期更换停车位请同步更新 `config/nav2_params.yaml` 里的 `initial_pose`。

> **机制说明**：不给初始位姿时，AMCL 不发布 `map→odom`，Humble 下 global_costmap 激活会卡在等 TF，后续 planner / bt_navigator 一直激活不了（表现为发目标点无响应）。这是**无限期等待而非超时睡死**——任何时候补上初始位姿，链路都会继续激活恢复。

## 🛠️ 核心架构与黑科技优化

本功能包不仅是简单的配置文件堆砌，而是针对地牛（三轮底盘 / 极强机动性）的物理特性做了深度重构，主要包含以下核心优化：

### 1. 静止漂移的终极克星 (定海神针 EKF)
室内的强磁场干扰会导致底盘的 BNO085 陀螺仪在静止时产生 3~5 度的缓慢漂移。
- **解决机制**：在 `ekf.yaml` 中，强制融合了轮式里程计的角速度（`vyaw`）。在车辆完全静止时，车轮输出极其精准、稳定的**零角速度**，EKF 依靠这个“锚点”强行抵消了 IMU 的地磁漂移，彻底解决了 RViz 中点云旋转歪斜的问题。

### 2. AMCL 噪声极简平衡
因为底盘位姿已经被 EKF 死死锁住，AMCL 就不再需要靠“大噪声”来容错：
- 将平移和旋转噪声（`alpha1` ~ `alpha5`）全部大幅下调至 `0.05`，杜绝了车辆静止时 AMCL 粒子“梦游”导致的平移发散。
- 更新门槛调至极度敏锐（移动 `0.05m` 或转动 `0.10rad` 即更新），确保运动中的微小漂移被雷达瞬间纠正。

### 3. 解锁 90度 原地转向封印
地牛的转向轮支持 90 度极限转向，这意味着它具备近乎**以后轴中心为圆心原地打转**的机动性。
- `minimum_turning_radius`（最小转弯半径）被极致压缩至 `0.05m`。
- `min_lookahead_dist`（纯追踪前瞻距离）降低至 `0.50m`。
- 效果：规划器再也不会在直角弯产生“无法通行”的误判，底层控制器在过窄门和 90度 弯时，会紧贴墙壁画出极小半径的锐角轨迹，彻底释放了车体的物理机动极限。

### 4. 严丝合缝的自遮挡与碰撞轮廓
- 剔除了之前冗余配置导致的车头前方“幽灵空气”（虚假占用），将全局与局部的 `footprint` 严格收缩至真实的物理边界 `[-0.30m, 1.60m]`。
- Nav2 的绿色防撞框现在像紧身衣一样完美贴合橙色车身，倒车、避障如丝般顺滑。

## 📂 目录结构与配置入口

- `config/lsx10.yaml`：镭神 N10 雷达驱动配置（指定了符号链接 `/dev/n10_lidar`）。
- `config/ekf.yaml`：多源传感器融合配置，负责输出极其稳定的 `odom -> base_link`。
- `config/nav2_params.yaml`：Nav2 核心算法池。包含 AMCL 调优、Regulated Pure Pursuit 控制器、90度转向惩罚函数及代价地图的极速衰减设定。
- `launch/n10_nav_all.launch.py`：唯一入口脚本，负责串联所有生命周期节点。
- `maps/`：存放了 N10 扫描出的默认 2D 栅格地图（建图完成后请将 `map.pgm` 和 `map.yaml` 保存在此处以供默认加载）。

## ⚠️ 常见问题

**Q: 启动后报错找不到雷达端口？**
A: Docker 容器启动时可能没有将后插的雷达 USB 口映射进来。尝试拔插雷达，或者在启动参数中显式指定宿主机识别到的串口：

```bash
ros2 launch diuniu_n10_nav n10_nav_all.launch.py serial_port:=/dev/ttyACM0
```

（推荐修改宿主机 udev 规则，将雷达永久绑定为 `/dev/n10_lidar` 即可免加参数）。
